## 8. Fotos

Crie a pasta `fotos/` na raiz do projeto e jogue as imagens lá dentro.
Nomeie assim (o sistema importa sozinho e já vincula ao produto certo):

```
fotos/
  chaveiro-gato_venda_1.jpg        <- vira foto de VENDA do produto "chaveiro-gato"
  chaveiro-gato_venda_2.jpg
  chaveiro-gato_fabricacao_1.jpg   <- vira foto de FABRICAÇÃO (processo/setup)
  vaso-espiral_venda_1.png
  impressora_ender3.jpg            <- foto da impressora
```

Regra: `nome-do-produto_venda_N.jpg` ou `nome-do-produto_fabricacao_N.jpg`.
Qualquer formato serve (jpg, png, heic do iPhone, webp). Se errar o nome, dá pra
arrastar e corrigir dentro do sistema depois.
